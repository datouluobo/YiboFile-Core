# 标签页交互系统设计规约

## 一、概述

本文档定义标签页（Tab）系统的交互行为规约。采用**正交维度组合架构**，将标签页行为解构为三个独立维度，用户可通过设置项自由组合。

> 标签页**视觉样式**（圆角、高度、指示条等 14 个 UI Token）详见 [UI系统最终规约](../../../docs/架构与规约/UI系统最终规约.md) 第五章 A 节。本文档仅关注**交互行为**层面。

## 二、正交维度定义

### 2.1 维度 1：宽度策略（TabWidthStrategy）

决定"每个标签多宽"。

| 策略 | 枚举值 | 描述 | 关联参数 |
|------|--------|------|----------|
| 固定宽度 | `Fixed` | 所有标签使用相同的固定宽度 | `TabFixedWidth` (80-250，默认 140) |
| 自适应宽度 | `Adaptive` | 每个标签根据标题文本长度自适应 | `TabMaxWidth` (100-300，默认 200) |
| 弹性宽度 | `Elastic` | 标签平分可用空间，始终填满一行 | `TabMaxWidth` (100-300，默认 200) |

### 2.2 维度 2：溢出策略（TabOverflowStrategy）

决定"标签放不下时怎么办"。

| 策略 | 枚举值 | 描述 | 兼容性 |
|------|--------|------|--------|
| 滚动模式 | `Scroll` | 标签保持宽度不变，超出容器时启用水平滚动 | Fixed ✅ Adaptive ✅ Elastic ❌ |
| 压缩模式 | `Compress` | 所有标签等比缩小至 MinWidth，优先保持一行可见 | Fixed ✅ Adaptive ✅ Elastic ✅ |

> 说明：Elastic + Scroll 无意义（弹性本身不会溢出），系统自动忽略溢出策略。

### 2.3 维度 3：显示优化（独立布尔开关）

| 开关 | 配置键 | 默认值 | 描述 |
|------|--------|--------|------|
| 关闭按钮动态隐藏 | `HideCloseButtonOnInactive` | `true` | 非活动标签隐藏关闭按钮，悬停时淡入显示 |
| 溢出导航箭头 | `ShowOverflowArrows` | `true` | 溢出时在标签栏两端显示 ‹ › 箭头按钮 |
| 溢出渐变遮罩 | `ShowOverflowGradient` | `true` | 溢出侧显示半透明渐变，暗示有更多标签 |

## 三、组合效果——还原主流软件风格

| 目标风格 | 宽度策略 | 溢出策略 | 隐藏关闭 | 箭头 | 遮罩 |
|---------|---------|---------|---------|------|------|
| Chrome / Edge | Elastic | Compress | ✅ | — | — |
| VS Code | Fixed | Scroll | ✅ | ✅ | ✅ |
| Firefox | Adaptive | Compress | ✅ | ✅ | ✅ |
| 传统文件管理器 | Fixed | Compress | ❌ | — | — |

## 四、技术架构

### 4.1 策略模式

```
TabWidthCalculator（组合器）
  ├── IWidthStrategy（3 种实现：Fixed / Adaptive / Elastic）
  └── IOverflowStrategy（2 种实现：Scroll / Compress）
```

计算流程：
1. `IWidthStrategy.CalculateNaturalWidths()` → 返回每个标签的理想宽度
2. `IOverflowStrategy.ApplyOverflow()` → 应用溢出逻辑，返回最终宽度
3. 写入 `PathTab.TargetWidth` → XAML 绑定自动更新 UI

### 4.2 配置模型

```csharp
// 枚举
public enum TabWidthStrategy { Fixed, Adaptive, Elastic }
public enum TabOverflowStrategy { Scroll, Compress }

// AppConfig 字段
TabWidthStrategy    // 宽度策略（默认 Adaptive）
TabOverflowStrategy // 溢出策略（默认 Scroll）
TabFixedWidth       // Fixed 模式标签宽度（默认 140）
TabMaxWidth         // Adaptive/Elastic 模式最大宽度（默认 200）
TabMinWidth         // 所有模式下的最小宽度（默认 50）
HideCloseButtonOnInactive  // 隐藏关闭按钮（默认 true）
ShowOverflowArrows         // 显示溢出箭头（默认 true）
ShowOverflowGradient       // 显示溢出遮罩（默认 true）
```

### 4.3 UI 结构

```
TabManagerControl
├── ScrollLeftButton（左导航箭头，溢出时显示）
├── ScrollViewer（HorizontalScrollBarVisibility="Hidden"）
│   └── ItemsControl → StackPanel(Horizontal)
├── GradientLeft（左渐变遮罩，覆盖在 ScrollViewer 上方）
├── GradientRight（右渐变遮罩）
├── ScrollRightButton（右导航箭头）
└── NewTabButton（新建按钮）
```

### 4.4 关闭按钮行为

- **活动标签**：始终显示关闭按钮（Opacity 0.6）
- **非活动标签**：默认隐藏，鼠标悬停整个标签时淡入显示（0.15s 动画）
- 可通过 `HideCloseButtonOnInactive = false` 恢复始终显示

## 六、迁移说明

旧配置字段与新字段的对应关系：

| 旧字段 | 新字段 | 说明 |
|--------|--------|------|
| `TabWidthMode.FixedWidth` | `TabWidthStrategy.Fixed` + `TabOverflowStrategy.Compress` | 旧"固定宽度"实际上是固定+压缩 |
| `TabWidthMode.DynamicWidth` | `TabWidthStrategy.Adaptive` + `TabOverflowStrategy.Compress` | 旧"动态宽度"实际上是自适应+压缩 |
| `PinnedTabWidth` | `TabFixedWidth` | 命名修正，消除与"钉住标签"的歧义 |
