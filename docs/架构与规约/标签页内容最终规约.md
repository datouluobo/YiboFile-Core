### 步骤 3.1：创建 PaneContentHost.xaml

**新建文件**: `Controls/PaneContentHost.xaml` + `.cs`

**XAML 结构**:

```xml
<UserControl>
    <!-- 内容呈现区: 根据 ActiveTab 切换 -->
    <Grid>
        <!-- 文件浏览器 (默认) -->
        <controls:FileBrowserControl x:Name="FileBrowserView"
            Visibility="Collapsed"/>

        <!-- 自定义内容区 -->
        <ContentPresenter x:Name="CustomContentPresenter"
            Visibility="Collapsed"/>
    </Grid>
</UserControl>
```

**Code-behind 核心逻辑**:

```
属性:
  - ActiveTab: PathTab (DependencyProperty, 绑定 ViewModel 的 ActiveTab)

监听 ActiveTab 变化:
  1. 如果 ActiveTab == null → 隐藏两者
  2. 如果 TabContentTypes.IsFileBrowserType(ActiveTab.ContentTypeId) →
       显示 FileBrowserView, 隐藏 CustomContentPresenter
  3. 否则 →
       var content = ActiveTab.CustomContent
           ?? _registry.Resolve(ActiveTab.ContentTypeId);
       ActiveTab.CustomContent = content;  // 缓存
       var view = content.CreateView();
       CustomContentPresenter.Content = view;
       显示 CustomContentPresenter, 隐藏 FileBrowserView
       content.OnActivated();

  切离时:
       oldContent?.OnDeactivated();
```

**关键设计**:
- `FileBrowserControl` 实例始终存在（不销毁不重建），只是通过 Visibility 切换
- 自定义面板通过 `ContentPresenter` 显示，View 实例由 `ITabContent` 缓存
- `TabContentRegistry` 通过 DI 注入（或从 `App.ServiceProvider` 解析）

```csharp
/// <summary>
/// 创建特殊标签页。AllowMultiple=false 时先查找已存在的同类型标签。
/// </summary>
public PathTab CreateSpecialTab(string contentTypeId, bool activate = true)
{
    // 1. 如果 AllowMultiple=false，查找已存在的同类型标签
    var existing = _tabs.FirstOrDefault(t => t.ContentTypeId == contentTypeId);
    if (existing != null)
    {
        if (activate) SetActiveTab(existing);
        return existing;
    }

    // 2. 从 Registry 解析元数据
    var content = _registry.Resolve(contentTypeId);
    if (content == null) return null;

    // 3. 创建标签
    var tab = new PathTab
    {
        ContentTypeId = contentTypeId,
        Title = content.Title,
        IconKey = content.IconKey,
        Path = $"content://{contentTypeId}",
        CustomContent = content,
        CloseCommand = ...,
        SelectCommand = ...,
    };

    AddTab(tab);
    if (activate) SetActiveTab(tab);
    return tab;
}
```
