# 侧边栏与界面 UI 优化方案

## 一、方案目标

针对当前 YiboFile 主界面与侧边栏（`NavigationRailControl`）存在的设计瑕疵和交互不足，提出系统性优化方案。核心目标是现代化视觉体验（去物理线化、统一尺寸、符合直觉的选中态反馈），并支持高级交互（侧边栏拖拽排序与自适应吸附）。由于本项目基于 MVVM 架构，所有改造必须遵循数据驱动原则。

## 二、侧边栏选中态视觉优化

### 1.问题背景
- 现有选中态通过 `Tag="Active"` 触发，仅仅只改变了前景色（在位图图标中甚至无效）。
- 原设计中的高亮背景色与侧边栏自身底色 `BackgroundSecondaryBrush` 重复，导致选中项在视觉上“隐形”。
- 图标大小不统一（顶部 `20x20`，中部 `18x18`），造成视觉上的杂乱感。

### 2.实施方案
- **统一图标尺寸**：将所有图标（矢量 `DrawingImage`）强行统一渲染尺寸为 `20x20`，外层按钮统一控制为 `40x40`。
- **重新定义选中反馈**：摒弃原本的左侧蓝色条，采用**大面积浅灰/带圆角的下压底板**。
  - 在 `RailButtonStyle` 的 ControlTemplate 中重写触发器。
  - Hover 态：设定为 `ControlHoverBrush`。
  - 选中/Active态：设定为比基础背景略深的 `BackgroundTertiaryBrush`，形成“按下/激活”的微浮雕感。

## 三、全局布局的无界分隔（Borderless）

### 1.问题背景
无论是侧边栏内部不同功能组之间，还是主界面的导航树、标签页、地址栏、双列表（DualList）等主功能区块之间，原本滥用了过多的实体物理分割线（`<Separator>` 或 `BorderThickness="1"` 的浅色线），视觉噪声大。

### 2.实施方案
- **去物理线段**：全面移除侧边栏（`NavigationRailControl`）与导航树（`NavigationPanelControl`）之间、各树状结构内部的静态硬性分隔线。
- **色彩层次区隔**：相邻大版块应通过色阶差异进行划分（例如 `#FFFFFF` 面板主体 与 `#F8F9FA` 导航栏背景）。利用留白（Margin/Padding）替代实线分割。
- **智能分割条（Splitter）**：保留原本的 GridSplitter 调整功能，但在默认状态下将热区背景设为 `Transparent`（隐藏物理线），仅在 Hover 时显现悬浮态效果。

## 四、侧边栏拖拽重拍与两端吸附架构设计

这是改进方案中最具挑战性和创新性的一环，主要解决侧边栏项目因在 XAML 中硬编码堆叠，导致用户无法自定义按钮顺序、无法实现自适应停靠的问题。

### 1. 数据驱动模型重构 (MVVM)
- **取消硬编码的 StackPanel**：所有的功能入口（Path、Library、Focus 等）不再作为静态 `Button` 放置在 XAML 中。
- **抽取按钮为数据模型（`NavigationRailItem`）**：在 ViewModel 中维护一个 `ObservableCollection<NavigationRailItem>`。模型需记录其基础信息（如图标路径/键、执行命令、标题）和当前所属状态（悬停、选中）。

### 2. 基于拖拽与占位的吸附交互机制
- 将原有的上、下端分隔布局，转换为单一或者带自适应中间弹性留白（`Spacer`）的拖放列表布局（或两个支持跨列表拖拽的 `ItemsControl` / `ListBox`）。
- **交互规范描述**：
  - 按钮可长按拖动，插入新的顺序。
  - 增加类似弹性“占位区（Spring Area）”概念：元素在经过占位区中线往上移动时，松手自动落入吸附上限（Top 区）；往下移动松手时，自动落入吸附下限（Bottom区）。
- **组件选型与封装**：由于基础 WPF 不原生提供复杂的自动排序吸附动画，需利用原生 `DragDrop` 事件体系，结合拖动反馈占位符（Adorner），进行功能适配（或引入稳健成熟的第三方库如 `GongSolutions.WPF.DragDrop`）。

## 五、实施与迭代步骤

1. **第一阶段：视觉降噪与图标整理**（已核准）
   - 设置 `<Image>` 资源加载时的长宽限定为 20x20。
   - 实现侧边栏按键圆角浅灰悬停/高亮框。
   - 彻底清除影响体验的非必要多余横竖分割线。
2. **第二阶段：拖拽体系数据抽象**
   - 编写 `NavigationRailItem` 领域模型并接入各主命令。
   - 将侧边栏的展示源重构挂载至 ViewModel 的集合绑定中，验证基本命令跳转功能正常。
3. **第三阶段：无感拖放与动态吸附落地**
   - 撰写完整的 Drag-and-Drop 扩展与算法。实现靠近哪侧就往哪侧吸附排序的高级动画过渡逻辑。
