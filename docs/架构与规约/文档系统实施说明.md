# 文档系统实施说明 (Core 专用)

## 1. 规约继承
本项目 (YiboFile-Core) 所有的文档生成与管理必须严格遵循主仓库的 [《文档目录结构规约》](../../docs/架构与规约/文档目录结构规约.md)。

## 2. 本地文档范围
在 `YiboFile-Core/docs/` 下仅保留符合以下条件的文档：
1.  仅属于 Core 项目的实现细节（如：`WPF 控件模板定义`）。
2.  仅在该项目内触发的 Bug 修复日志（如：`双面板刷新逻辑优化`）。
3.  CAD 等仅在 Core 中集成的特定组件说明。

## 3. 已完成迁移清单
以下架构级文档已根据分级原则迁回 **主仓库**：
*   配置系统架构规约
*   标签页内容架构/最终规约
*   UI系统最终规约
*   后续开发计划/已知问题追踪
*   开发工作流程/项目结构说明
