## 1. 概述 (Overview)

本文档旨在定义 **YiboFile** 在导航路径、双栏布局模式下的交互行为及焦点管理规范。核心目标是确保用户在复杂的文件管理场景中（特别是双栏模式）拥有清晰、可预测的操作体验，避免“焦点迷失”或“误操作”。

---

## 2. 导航逻辑 (Navigation Logic)

导航系统需统一处理多种类型的路径资源，确保在地址栏、标签页和侧边栏中的行为一致性。

### 2.1 路径类型定义
*   **物理路径 (Physical Path)**: 标准文件系统路径。
    *   示例: `C:\Users\Name\Documents`, `\\Server\Share`
*   **库路径 (Library Path)**: 虚拟聚合视图。
    *   示例: `lib://Documents`, `lib://Pictures`
    *   行为: 聚合显示多个物理位置的内容，不支持常规的文件系统操作（如直接新建文件夹），需映射到具体物理路径。
*   **标签路径 (Tag Path)**: 基于元数据的筛选视图。
    *   示例: `tag://ProjectA`, `tag://Urgent`
    *   行为: 显示所有包含特定标签的文件扁平列表。

### 2.2 链接交互行为
*   **左键单击 (Primary Click)**:
    *   **侧边栏/快速访问**: 仅更新 **侧边栏 (Sidebar)** 的选中状态（如高亮对应的库/驱动器），并驱动 **当前激活的面板 (Active Pane)** 内容跳转。
        *   *注意*: 切换侧边栏的“路径/库/标签”顶级分类按钮时，仅刷新侧边栏列表内容，**不得** 触发文件管理面板的任何导航或重置。反之，当文件面板导航（如切换标签页）时，**不得** 强制改变侧边栏的当前模式（库/路径/标签），除非该路径是显式由侧边栏点击触发的。
    *   **面包屑导航**: 跳转至父级目录，刷新当前面板内容。
*   **中键单击 / Ctrl+单击 (Middle Click / Ctrl+Click)**:
    *   **任何链接**: 在 **当前激活面板** 的 **新标签页** 中打开目标路径。
    *   **特殊情况**: 如果在非激活面板的区域触发，应先激活该面板，再执行打开新标签页操作。

## 3. 双栏布局与视图 (Dual Pane Layout)

双栏模式是高效文件管理的核心。系统将界面分为 **主面板 (Pane A)** 和 **副面板 (Pane B)**（逻辑上对等）。

### 3.1 视觉区域划分
每个面板 (Pane) 应包含独立的以下元素，形成闭环的导航上下文：
1.  **标签栏 (Tab Bar)**: 显示该面板打开的所有路径标签。
2.  **地址/工具栏 (Address/Tool Bar)**: 
    *   显示主要路径信息。
    *   工具栏操作（如排序、视图切换）仅作用于 **当前面板**。
3.  **文件列表 (File List)**: 核心内容区域。
4.  **状态栏信息 (Status Info)**: 选中项计数、大小等（可共享底部状态栏，但需根据焦点切换显示内容）。

### 3.2 标签页管理 (Tab Management)
*   **独立性**: Pane A 和 Pane B 的标签页列表完全独立，互不干扰。
*   **新建标签页**:
    *   快捷键 `Ctrl+T` 应在 **当前激活面板** 中新建标签页。
    *   默认路径：继承当前标签页的路径或设为“此电脑/主页”。
*   **关闭标签页**:
    *   关闭最后一个标签页时，不应关闭面板，而是导航至默认页面或保留空标签。

### 3.3 标签页复用与激活策略 (Tab Reuse & Activation Strategy)

为平衡“上下文连续性”与“防止标签冗余”，系统根据操作来源采用 **动态优先级策略**：

#### 3.3.1 场景 A: 列表内钻取 (List Drill-down)
*   **触发**: 双击文件夹 / 选中后回车。
*   **优先级 0 (最高)**: **强制复用当前标签页**。
    *   即使目标子目录已在同面板的其他标签页打开，也 **不跳转** 到那个标签页，而是直接在当前标签页进入。
    *   *例外*: 若用户按住 `Ctrl` 或 `Middle Click`，则强制在 **新建标签页** 打开。

#### 3.3.2 场景 B: 外部导航 (External Navigation)
*   **触发**: 点击侧边栏、地址栏输入、面包屑跳转、命令行调用。
*   **优先级流程**:
    1.  **排重检测 (De-duplication)**
        *   若目标路径已在 **当前激活面板** 的其他标签页中打开 -> **切换并激活** 该标签页。
        *   如果有多个，激活第一个。
    2.  **同构复用 (Isomorphic Reuse)**
        *   若目标路径未打开，且当前标签页未锁定 -> **复用当前标签页** 跳转。
        *   *平权原则*: 物理路径、库 (`lib://`)、标签 (`tag://`) 视为 **同构资源**，允许互相在同一标签页内跳转，**不**强制新建。
    3.  **新建标签页 (New Tab Fallback)**
        *   若当前标签页被锁定，或显式请求新标签页 -> **新建标签页** 并激活。

#### 3.3.3 视觉保障 (Visibility Assurance)
*   **自动滚动**: 无论通过何种方式（点击、自动复用、键盘切换）**激活** 了一个标签页，标签栏必须自动执行滚动操作，确保该标签页处于 **可见区域** 内。

### 3.4 面板内状态一致性 (Intra-Pane State Consistency)
*   **绝对同步原则**: 
    *   任意时刻，同一面板内的 **当前激活标签页**、**地址栏显示路径** 与 **文件列表内容** 必须保持 **严格一致 (Strict Consistency)**。
    *   *禁忌*: 决不允许地址栏显示路径 A，而文件列表展示路径 B 的内容；也不允许标签页高亮 A，但地址栏或文件列表仍停留在 B 的状态。
*   **原子性更新 (Atomic Updates)**: 
    *   导航操作（无论是点击标签、跳转地址还是钻取目录）必须作为 **原子事务** 执行。
    *   要么全部UI组件（标签、地址、列表、信息区）同时更新成功，要么在出错时全部回滚，**杜绝** 出现“部分更新”的中间状态。

## 4. 焦点管理 (Focus Management)

焦点管理是双栏体验的灵魂。必须明确 **“激活面板 (Active PaneContext)”** 的概念，所有键盘指令和上下文相关操作仅针对激活面板执行。

### 4.1 激活状态定义
*   **视觉反馈**:
    *   **激活面板**: 标题栏/标签栏高亮，文件列表背景色正常，选中项高亮显示，颜色方框包含住标签页、地址栏、文件列表、文件信息区域
    *   **非激活面板**: 整体UI变暗 (Dimmed)，选中项变为灰色（非活动选中态）（视觉反馈需明显，让用户一眼即可识别 `Ctrl+V` 或 `Delete` 会作用于哪里）。

### 4.2 焦点切换触发 (Focus Triggers)
1.  **鼠标操作**:
    *   单击面板内的任何区域（文件列表、空白处、标签、地址栏）即强制将该面板设为 **激活**。
    *   *防误触*: 简单的激活点击不应触发文件打开操作，除非点击的是具体的可交互元素。
2.  **键盘操作**:
    *   **`Tab` 键 (默认行为)**: 在 **主面板 (Pane A)** 和 **副面板 (Pane B)** 的核心焦点区（通常是文件列表）之间切换。
        *   *设计意图*: 双栏操作的核心是快速搬运，`Tab` 键应服务于最高频的跨面板切换。
        *   *配置项*: 此行为应在设置中可自定义（例如改为 Windows 风格的控件循环）。
    *   **`Ctrl+Tab`**: 切换面板内的标签页。

### 4.3 典型场景焦点的流转
*   **场景 1: 从侧边栏点击库**
    *   用户点击左侧导航栏的 "下载"。
    *   结果: **当前激活的面板** 跳转至 "Downloads"。焦点保留在文件列表中。
*   **场景 2: 复制文件**
    *   用户在左栏选中文件 -> 按 `F5` (或复制按钮)。
    *   弹窗确认目标为右栏路径。
    *   操作完成后，焦点保持在 **源面板 (左栏)**，方便继续操作。
*   **场景 3: 启动应用**
    *   应用启动时，默认 **左面板 (Pane A)** 为激活状态，焦点位于文件列表的第一项。

## 5. 地址栏与工具栏交互 (Address & Toolbar Interaction)

### 5.1 地址栏行为
*   **同步显示**: 地址栏必须实时反映 **激活标签页** 的当前路径。
*   **编辑模式**: 
    *   点击地址栏进入编辑模式。
    *   输入新路径并回车 -> 在 **当前面板** 的当前标签页跳转。
    *   输入新路径并Ctrl+Enter -> 在 **当前面板** 的新标签页跳转。
    *   `Alt+D` 快捷键: 聚焦 **激活面板** 的地址栏。

### 5.2 工具栏与面板焦点 (Toolbar & Focus)
*   **点击即激活 (Activation on Click)**: 
    *   点击工具栏按钮时，系统必须 **首先** 将焦点强制转移到该按钮所属的面板 (Pane)。
    *   *执行顺序*: 
        1.  用户点击 Pane A 的 [复制] 按钮。
        2.  系统检测 Pane A 是否激活。若否，激活 Pane A（视觉高亮）。
        3.  执行 [复制] 命令（作用于 Pane A 的选中项）。
    *   *跨面板操作示例*: 此时若用户接着去点击 Pane B 的 [粘贴] 按钮：
        1.  系统激活 Pane B。
        2.  执行 [粘贴] 命令（将剪贴板内容粘贴到 Pane B 的当前路径）。
*   **作用域严格绑定**: 工具栏按钮的操作对象永远是其 **物理所属** 的面板，无关点击前的焦点状态。

## 6. 异常与边界情况 (Edge Cases)

*   **单栏模式切换**: 
    *   切换回单栏模式时，保留 **当前激活面板** 的内容作为主视图，隐藏非激活面板。
*   **路径无效**: 
    *   如果导航路径不存在，应在当前面板显示错误页或保留在上一有效路径，并弹出非阻塞式提示（Toast）。
*   **长耗时加载**:
    *   加载大文件夹时，**不应阻塞** 另一个面板的操作。每个面板的加载过程应在独立线程/任务中进行，并显示各自的进度指示器。

## 7. 默认行为与可配置项 (Defaults & Configurables)

| 功能点 | 默认行为 (Default Rule) | 可配置性 (Configurability) |
| :--- | :--- | :--- |
| **Tab 键** | 切换面板焦点 (Toggle Pane Focus) | [ ]使用 Windows 标准控件循环 |
| **新建标签页** | 复制当前标签页 (Duplicate Current) | [ ] 打开主页 / 空白页 |
| **关闭最后标签** | 导航至 "驱动器总览" (Root/My Computer) | [ ] 关闭面板 / 关闭应用 |

## 8. 统一性原则 (Uniformity Principles)

为了降低认知负荷，系统中的以下概念应保持 **视觉与行为的平权 (First-class Citizen Equality)**：

*   **路径平权**: `物理路径`、`库 (Library)`、`标签 (Tag)` 三者在导航栏、标签页、地址栏中地位均等，**无差别** 支持标签页复用、面包屑导航和书签收藏。
*   **入口平权**: `快速访问`、`驱动器`、`收藏夹 (自定义文件夹)` 在侧边栏和主页中地位均等，点击行为必须严格一致。
